# DL-Projects

A growing collection of deep learning projects implemented in **PyTorch**, focusing on
computer vision, multimodal learning, and experimental evaluation of modern neural architectures.

This repository serves as a workspace for academic and research-oriented projects, including
paper re-implementations, architectural explorations, and empirical analysis.

---

## 📂 Current Projects

### 🔹 SAN for Visual Question Answering (VQA)
An attention-based deep learning project for **Visual Question Answering**, exploring
multi-step reasoning over images and questions.

**Contents:**
- `SAN_for_VQA.ipynb` — Full implementation, training, and evaluation
- `SAN for VQA - Final Report.pdf` — Final project report with methodology and results

This project investigates attention mechanisms for multimodal reasoning and evaluates
model performance using standard VQA metrics.

---

### 🔹 VGGT Seminar — Visual Geometry from Multiple Views

A controlled reproduction and evaluation of **VGGT: Visual Geometry Grounded Transformer**
on calibrated real scenes from ETH3D and synthetic ground truth from TartanAir.

**Highlights:**
- Official VGGT-1B inference reproduced on an RTX 5080
- Nested 2/4/6/8/10-view evaluation
- Camera, depth, confidence, runtime, and memory analysis
- Leakage-safe bounded camera/depth-head adaptation
- Submission-ready 16-page report with verified equations and figures
- 88 download-free tests

**Start here:**
- [`VGGT-Seminar/README.md`](VGGT-Seminar/README.md)
- [`VGGT-Seminar/report/submission/Peleg_Shpitzer_Razi_Mreeh_VGGT_Seminar_Report.pdf`](VGGT-Seminar/report/submission/Peleg_Shpitzer_Razi_Mreeh_VGGT_Seminar_Report.pdf)

Large datasets, model checkpoints, and generated experiment outputs remain excluded.
