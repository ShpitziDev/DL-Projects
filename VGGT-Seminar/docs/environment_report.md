## Warnings

- Global Python 3.12 plus a nightly Torch build is useful evidence that the GPU works, but is not the recommended reproducible environment.
- Official VGGT `requirements.txt` pins Torch 2.3.1 / torchvision 0.18.1, while `pyproject.toml` only requires Python >=3.10 and does not pin Torch. The old pin should be treated as historical for this GPU.
- `nvidia-smi` showed other GUI processes using GPU memory; record a clean baseline before benchmarking.
- The Windows sandbox runner returned error 1312 intermittently during inspection; the checks were repeated read-only outside it.

## Recommendation

Use native Windows, Python 3.11, a dedicated environment named `vggt-seminar`, and an official stable PyTorch wheel explicitly supporting RTX 5080. Validate a tiny CUDA tensor allocation before adding VGGT. Keep WSL as a documented fallback for optional dependencies, not the default.
